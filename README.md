# Memory Manager in C

Um gerenciador de memória desenvolvido em C para estudar
alocação dinâmica, gerenciamento de blocos e fragmentação.

## Objetivos

- Implementar gerenciamento de memória baseado em blocos
- Implementar First Fit
- Implementar Best Fit
- Implementar Worst Fit
- Implementar liberação de memória
- Implementar coalescência de blocos
- Criar testes automatizados

## Tecnologias

- C
- GCC
- Git
- GitHub
